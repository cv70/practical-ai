## 📖 章节内容

### 1. 机器学习概述
- 什么是机器学习？
  - 机器学习是人工智能的一个分支，它使计算机能够在不被明确编程的情况下从数据中学习并做出预测或决策
  - 通过算法解析数据，从中学习，并基于学习结果对新数据进行预测或判断
  - 广泛应用于推荐系统、图像识别、自然语言处理、金融风控等领域

- 机器学习的类型：
  - 监督学习：使用带有标签的训练数据进行学习，目标是预测新数据的标签，包括回归和分类任务
  - 无监督学习：使用没有标签的数据进行学习，目标是发现数据中的隐藏模式或结构，如聚类和降维
  - 强化学习：通过与环境交互，根据奖励信号学习最优行为策略，常用于游戏AI和机器人控制

- 机器学习工作流程：
  1. 问题定义：明确业务目标和机器学习任务类型
  2. 数据收集：获取相关的训练数据
  3. 数据预处理：清洗、转换和标准化数据
  4. 特征工程：提取和选择有效的特征
  5. 模型选择：根据任务类型选择合适的算法
  6. 模型训练：使用训练数据训练模型
  7. 模型评估：使用验证数据评估模型性能
  8. 模型优化：调整超参数以提升性能
  9. 模型部署：将训练好的模型应用到生产环境中
  10. 模型监控与更新：持续监控模型性能并在必要时重新训练

### 2. 监督学习
- 回归问题：预测连续值输出，如房价预测、销售额预测等
- 分类问题：预测离散类别标签，如图像分类、邮件垃圾分类等
- 常用算法：
  - 线性回归：用于建立特征与目标之间的线性关系，适用于简单的回归任务
  - 逻辑回归：用于二分类或多分类问题，通过sigmoid函数将线性回归输出映射到概率
  - 神经网络：多层感知器，可以解决复杂的非线性问题，是深度学习的基础

### 3. 无监督学习
- 聚类分析：发现数据中的自然分组，如客户细分、基因序列分析等
- 降维技术：减少特征数量同时保留重要信息，有助于数据可视化和降低计算复杂度
- 常用算法：
  - K-means：将数据划分为K个簇，使得同一簇内的数据点相似度高，不同簇间的相似度低
  - 主成分分析(PCA)：通过线性变换将数据投影到低维空间，保留数据中方差最大的方向
  - 自编码器：使用神经网络进行非线性降维，能够学习数据的复杂特征表示

### 4. 模型评估与优化
- 训练集、验证集、测试集的作用和划分原则：
  - 训练集：用于训练模型参数
  - 验证集：用于调整超参数和选择模型
  - 测试集：用于最终评估模型性能，模拟真实环境
- 交叉验证：K折交叉验证等方法提高模型评估可靠性，减少因数据划分带来的偶然性
- 性能指标：
  - 准确率：分类正确的样本占总样本的比例，适用于平衡数据集
  - 均方误差(MSE)：回归任务中预测值与真实值差的平方的平均值，值越小表示拟合越好
  - R²分数：衡量模型解释数据变异程度的统计量，取值范围[0,1]，越接近1表示模型越好
- 超参数调优：网格搜索、随机搜索等方法寻找最优参数组合，提升模型性能
