## 🧪 实践练习

### [小项目：学生 grades 分析系统 code/student_grade_analysis_project.py](./code/student_grade_analysis_project.py)

这是一个综合性的数据分析项目，结合了本章所学的所有知识点：

1. **数据生成**：使用 NumPy 生成模拟的学生 grades 数据
2. **数据处理**：使用 Pandas 进行数据清洗、分析和处理
3. **统计分析**：计算各项统计数据，如平均分、标准差等
4. **数据可视化**：使用 Matplotlib 创建多种图表展示分析结果
5. **结果保存**：将分析结果保存为 CSV 文件

运行项目：
```bash
python code/student_grade_analysis_project.py
```

项目输出：
- 控制台显示详细的分析报告
- `output/` 目录下生成多个可视化图表
- `output/student_grades_analysis.csv` 包含完整的分析结果
